### 20260313-181326 Quarto Heading Truncation With Meta Shortcode And Equals

- Symptom: `offbeat-count/the-crossing-point-of-language-and-music/en/` rendered only partially in final HTML. The page stopped after the `Basic Knowledge of ...` heading.
- Diagnosis: the split source generated by Rhythmpress was healthy. The truncation happened in the Quarto render path, not in the splitter and not only in the browser. The broken result was visible in both the rendered HTML and `.site-en/search.json`.
- Root cause pattern: the problematic heading was `### Basic Knowledge of {{<meta var.METRE.en>}} = Stress Beats` in [offbeat-count/master-en.md](/Users/ats/rhythmdo-com/offbeat-count/master-en.md). Plain Pandoc accepts `=` in headings, so the issue is narrower: Quarto 1.7.31 appears to mishandle the combination of an ATX heading, a `{{<meta ...>}}` shortcode, and ASCII `=` immediately after the shortcode expansion point.
- Fix applied: changed the heading to `### Basic Knowledge of {{<meta var.METRE.en>}}: Stress Beats`, then regenerated the split page, rendered the affected English page, and reassembled `.site`.
- Verification: the rendered page now includes `Basic Knowledge of Metre: Stress Beats`, `Metre Has Many Forms`, and `About Nursery Rhyme` in both `.site-en` and `.site`. The English search index also contains the full page content again.
- Follow-up scan: no other current English translation source uses the same shortcode-plus-ASCII-`=` heading pattern. Several headings use `=` without shortcodes, and those render normally.
- Separate issue found: `offbeat-count/how-to-pronounce-the-offbeat-count-correctly/en/index.qmd` contains a commented-out appendix block beginning at `### 付録`; this is a different syntax oddity, not the same truncation bug.
- Remaining caveat: a full `render --profile en` still has an unrelated failure in `multidimensional-division-spaces` unless `RHYTHMPRESS_ROOT` is set for that notebook import path.
